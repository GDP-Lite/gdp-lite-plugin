# GDP Lite 2.0.5 LTS

Production baseline for the GDP Platform.

## Included
- Versioned database upgrades
- Role capabilities
- Site Health integration
- GDP Lite Health Check page
- Corrected autoloader class map
- Query, REST, template, cache and developer frameworks

## Compatibility
- WordPress 6.4+
- PHP 8.0+
- No Composer required

## Upgrade
Upload the ZIP through Plugins > Add New > Upload Plugin and replace the existing version. Existing games, terms, settings and templates are preserved.
